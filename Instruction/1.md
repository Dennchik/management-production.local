	| -------------------------- | ---------- |
	| Задание → маршрут          | `RESTRICT` |
	| Выполнение → задание       | `CASCADE`  |

	| Вход → выполнение          | `CASCADE`  |
	| Вход → материал            | `RESTRICT` |

	| Выход → выполнение         | `CASCADE`  |
	| Выход → материал           | `RESTRICT` |
	| Выход → рулон              | `RESTRICT` |
	| Этап маршрута → операция   | `RESTRICT` |
	| Этап маршрута → маршрут    | `CASCADE`  |

2. Проверенные связи:
	```
	ProductionOperation
			  │
			  ▼
	ProductionRouteStep
			  │
			  ├── ProductionOperation
			  └── ProductionOperationExecution
						     |
					  ┌──────────┴──────────┐
					  ▼                     ▼
		  ProductionOperationInput   ProductionOperationOutput
					  │                     │
					  ├── Material          ├── Material
					  └── MaterialRoll      └── MaterialRoll
	```

	Например, маршрут сможет быть:
	```
	Маршрут A
	1. Ламинация
		Материал 1 + Материал 2 + Клей
			  ↓
		ПФ-1
			  ↓
	2. Печать
			  ↓
	3. Резка
	```
	
	или:
	```
	Маршрут B
	1. Ламинация
		Материал 1 + Материал 2 + Клей
			  ↓
		ПФ-1
			  ↓
	2. Печать
			  ↓
	3. Кэширование
		ПФ-1 + Материал 3 + Клей
			  ↓
		ПФ-2
			  ↓
	4. Резка
	```
