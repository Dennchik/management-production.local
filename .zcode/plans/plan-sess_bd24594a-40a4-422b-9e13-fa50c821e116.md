# Дозабор рулонов в работе + завершение по остатку рулона

Оператор при завершении всегда указывает, сколько ОСТАЛОСЬ в рулоне; расход (= текущий вес рулона − введённый остаток) списывается системой. Пока задача «В работе», можно взять дополнительный рулон по входному материалу.

## 1. Маршруты (`routes/web.php`, группа задач)
- `GET /tasks/{task}/inputs` → `addInputForm` — форма дозабора рулонов.
- `POST /tasks/{task}/inputs` → `addInput` — добавление.

## 2. Контроллер `ProductionTaskController`
- `addInputForm()`: только для `in_progress`; входные материалы задачи (с форматом), по каждому — рулоны того же формата с остатком > 0, ИСКЛЮЧАЯ рулоны, уже взятые этой задачей (уникальность на контроллере + в БД не дублируем).
- `addInput()`: валидация как у `start()` (`inputs.*.material_id|roll_id|planned_weight`); материал обязан быть входом этой задачи; рулон не должен уже быть в задаче (иначе ошибка валидации «Рулон уже взят»); создаёт дополнительные строки `ProductionTaskInput` (существующие не трогает).
- `completeForm()`: без изменений по данным (строки inputs уже включат добавленные рулоны).
- `complete()`: поле `inputs.*.remaining` (обязательное, ≥ 0). Для каждого входа в транзакции: рулон берётся `lockForUpdate`; проверка `remaining ≤ текущий вес рулона` (иначе ошибка «Остаток не может превышать …"); `used = вес − remaining`; при `used > 0` создаётся `MaterialIssue(weight: used)` и `ProductionTaskInput.actual_weight = used`; рулону записывается `weight = remaining`. Комментарий/выходы — без изменений.

## 3. Вьюхи
- Новая `tasks/inputs.blade.php` («Взять рулоны»): разметка как у start-формы (материал — формат в подписи, селект рулонов, плановый вес), но заполняет только нужные строки; пустые не отправляются (JS-отсечение не нужно — plain select с пустым «— Не выбран —»).
- `tasks/complete.blade.php`: вместо «Фактически израсходовано» — поле «Остаток в рулоне, кг» (`inputs[i][remaining]`), предзаполнено текущим весом рулона; рядом подсказка «Сейчас в рулоне: X кг».
- `tasks/show.blade.php`: для `in_progress` кнопка «Взять ещё рулон» (route `tasks.inputs.form`) рядом с «Завершить задачу».

## 4. Проверка (tinker + браузер)
- Старт задачи → дозабор второго рулона (строки inputs растут, дубликат отклоняется) → завершение с остатками: расход = вес−остаток, `MaterialIssue` на расход, вес рулона = остаток, `actual_weight` = расход; остаток больше веса — ошибка валидации.
